# BandwagonHost legit：搬瓦工到底靠不靠谱，背景、退款政策和全部在售套餐一次看懂

搜 "BandwagonHost legit" 的人，担心的东西其实很集中：这家只做自助 VPS、没有在线客服、官网长得也不怎么时髦的商家，钱付了会不会打水漂。这个疑问很正常，搬瓦工的主要付款流程在英文网站上走完，社区讨论又大多集中在中文圈，第一次买的人很难不从“它是不是骗子”这个问题开始。

先把结论放在前面：**BandwagonHost（搬瓦工）是一家真实运营了十几年、有明确运营主体、退款政策成文的 VPS 商家**，不是皮包公司。但它也有几个明显的“不合适”：全自助服务、国内访问体验完全取决于你选的线路、热门套餐经常缺货。下文把这些拆开讲清楚，最后附上目前官网在售的全部套餐和价格。

## 先说结论：legit，但它不是给所有人准备的

判断一家 VPS 商家靠不靠谱，看三样东西就够：运营主体是否清晰、产品是否有自研的技术底子、出问题时的退出机制是否明确。搬瓦工这三项都能对上。

它由 IT7 Networks 运营，在面向中国用户的技术社区里活跃了十几年，控制面板 KiwiVM 是自研的，硬件和 IP 资源也是自己的。官方知识库明确写过：到期**不会自动从你的 PayPal 或信用卡里扣款**，续费全靠手动。这点对“怕被自动扣费”的用户来说是个实打实的安心项。

不合适的地方同样具体：这是严格的自管服务，装系统、配环境、查故障都自己动手，官方不帮你调试应用；所有套餐按流量计费，超了直接暂停而不是限速；适合中国访问的 CN2 GIA 套餐长期处于“看库存抢购”的状态。

## 它是什么：一家只做 KVM VPS 的“老派”商家

BandwagonHost 的产品线非常单一：KVM 架构的 Linux VPS，没有虚拟主机、没有建站套餐、没有所谓的企业级全家桶。所有机器跑在自研的 KiwiVM 面板上，开停机、重装系统、快照、rDNS 设置、机房迁移、API 调用都在面板里完成，下单后开通是即时的。

系统支持 AlmaLinux、RockyLinux、Debian、Ubuntu、CentOS 等主流发行版，也支持手动挂载 ISO 安装。每台机器带独立 IPv4 和 IPv6 /64 段，完整的 root 权限。

付款方式对国内用户比较友好，支持支付宝、PayPal、信用卡等常见渠道，购买和续费都能走支付宝，只是给账户充值余额这条路不走支付宝。这一点各种购买教程的说法基本一致。

## 为什么“中国线路”是它的招牌：CN2 GIA 到底值不值钱

搬瓦工官网有一篇讲得很实在的科普：中国电信对外的 IP 通道分好几档，最常见的是 AS4134（163 骨干网），便宜但高峰期拥堵，丢包率可以到 30% 以上；CN2 GT 想解决问题，但近几年实际表现和 163 差距不大；真正稳定的是 **CN2 GIA**（AS4809）和较新的 **CTGNet**（AS23764），代价是成本极高、容量极小。

这就是搬瓦工的护城河：它在洛杉矶机房部署了多条 10Gb 级的 CN2 GIA/CTGNet 链路。高端的电商系列回程走三条优质通道——电信 CN2 GIA、移动 CMIN2、联通 Premium（AS10099），并且和 Google 等大型网络在洛杉矶有直连互联。

你的网站或者应用如果只有海外访客，这些贵的线路对你没意义，买便宜的基础款就行。如果访问者主要在中国大陆，CN2 GIA 线路在晚高峰的表现和普通线路完全是两回事——这也是这个品牌能在中文社区立足这么多年的核心原因。

> 新注册账户 30 天内可申请全额退款；仅限新购订单，续费订单不适用；VPS 的 IP 必须处于可用状态（IP 已被封则不符合退款条件）。

## 常见问题

**流量用完了会怎样？** 机器会被自动暂停，等下个计费周期开始自动恢复，不会产生超额费用。着急恢复的话，只能升级到更高套餐。它不按超出量扣钱，这点和某些云厂商的“天价流量账单”路线完全不同。

**IP 被墙了怎么办？** 官方的说法是这类封锁通常会自行解除，时间从几天到几个月不等。电商系列可以靠免费切换机房换 IP，SLA 系列每两周能免费换一次 IP，基础款则基本只能认了再等。

**到期会自动扣款续费吗？** 不会。官方知识库明确说明从不自动从 PayPal 或信用卡扣款，续费需要手动操作，忘记续费机器到期停止，数据保留一段时间，不会凭空消失。

**能装 Windows 吗？** 官方系统列表以 Linux 为主，支持手动挂载 ISO 安装，但没有开箱即用的 Windows 镜像，也不含授权，动手能力一般的话不建议折腾。
